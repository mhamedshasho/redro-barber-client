# Redro Barber Client

Customer booking portal connected to the dedicated Redro Barber Supabase project.

- Email/password sign-up and login; no paid SMS provider.
- Permanent customer number generated by PostgreSQL identity sequence.
- Customer profile, appointment requests, appointment status, and queue position.
- Row Level Security restricts customers to their own records.
- Frontend duplicate-submit lock plus a unique database idempotency constraint.

## Deploy
The GitHub Actions workflow publishes the repository root to GitHub Pages. In repository Settings > Pages, select GitHub Actions.

## Free-only rule
Use Supabase Free and GitHub free public-repository/Pages allowances only. Do not upgrade or enable paid add-ons. If free quotas are reached, pause usage instead of paying.

## Cloud-only
No offline booking mode, IndexedDB, local business-data cache, or offline fallback. A working internet connection is required.
